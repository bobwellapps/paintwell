Paintwell 1.2

New
- Opening a picture from your file manager while Paintwell is open now adds it as a new tab
  in that Paintwell, instead of starting another copy.
- Paintwell is on the Snap Store: sudo snap install paintwell

Fixed
- Drag and drop from the file manager now works in the snap.
- Scanning works in the snap, including network printer-scanners (HP, Canon, Epson and more).
- Printing works in the snap.
- If Paintwell isn't allowed to read a dropped file, it now says so and explains how to allow it.
